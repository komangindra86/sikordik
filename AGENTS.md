# Alur penyelesaian fase SIKORDIK

- Repository tujuan pengguna: `https://github.com/komangindra86/sikordik.git` (remote `origin`).
- Setelah setiap fase selesai dan pengujian yang relevan lulus, simpan checkpoint commit dan push ke repository tersebut. Laporkan fase, hasil pengujian, dan commit yang berhasil dipush.
- Branch checkpoint saat ini adalah `main`. Periksa status lokal dan remote sebelum push; jangan force-push atau menimpa pekerjaan di remote. Jika ada konflik histori atau autentikasi gagal, laporkan kendalanya tanpa menghapus perubahan.
- Jangan commit/push `.env`, password, token, file kredensial bootstrap, unggahan privat, database lokal, log, atau backup. Pertahankan aturan `.gitignore`.
- Push checkpoint tidak berarti memulai fase berikutnya. Lanjutkan implementasi sesuai fase yang diminta pengguna.
