# Panduan ringkas SIKORDIK

Berlaku sejak penyederhanaan alur, Oktober 2026. Rincian tiap langkah ada di [buku panduan lengkap](PANDUAN-PENGGUNA.md); aturan yang berubah dicatat di [perubahan alur](PENYEDERHANAAN-ALUR.md).

## Tiga hal yang perlu diingat

1. **Buka Beranda.** Bagian *Tugas saya* berisi semua yang menunggu Anda, lengkap dengan tombolnya. Kerjakan dari atas ke bawah. Yang tidak ada di sana sedang menunggu orang lain.
2. **Satu peserta, satu halaman.** Menu *Penempatan* (peserta: *Stase saya*) membuka halaman penempatan dengan garis tahap, kalimat *Langkah berikutnya*, dan tab Dokumen, Pembimbing & jadwal, Presensi, Logbook, Nilai, serta Survei & penyelesaian.
3. **Menyetujui cukup satu klik; menolak harus beralasan.** Semua keputusan tetap tercatat atas nama akun Anda.

## Urutan satu stase

| Tahap | Siapa | Yang dilakukan |
|---|---|---|
| 1. Penerimaan | Admin Kordik | *Penerimaan peserta → Terima peserta baru*: isi surat, penempatan, dan daftar peserta (boleh tempel dari Excel). Periksa peserta lama, lalu *Simpan & ajukan*. |
| | Ketua KSM, lalu Tim Kordik | Di Beranda tekan *Putuskan sekaligus*, hilangkan centang bila perlu, *Setujui yang dicentang*. Menolak dilakukan dari halaman penempatannya. |
| 2. Dokumen | Admin Kordik | Di tab Dokumen tekan *Aktifkan akun* dan kirimkan tautan sekali pakai kepada peserta. |
| | Peserta | Masuk, buka *Stase saya → Dokumen*, unggah tiap dokumen. |
| | Admin Kordik | *Nyatakan valid* per dokumen, lalu *Semua dokumen lengkap — lanjutkan*. |
| 3. Pembimbing & jadwal | Admin Kordik / Sekretariat KSM | Tab Pembimbing & jadwal: pilih pendidik, *Ajukan ke Ketua KSM*. |
| | Ketua KSM | *Setujui*. |
| | Peserta | *Susun jadwal satu periode*: tanggal, hari, jam, lokasi, pembimbing → *Simpan & ajukan ke pembimbing*. |
| | Pembimbing | *Setujui semua*. Jadwal langsung terbit. |
| 4. Stase | Peserta | Tab Presensi: tekan *Hadir* pada hari itu. Izin/sakit lewat *Lainnya*. Stase mulai otomatis pada presensi pertama. |
| | Pembimbing | *Verifikasi yang dicentang* untuk banyak hari sekaligus. |
| | Peserta, Pembimbing | Logbook: *Simpan & ajukan*, lalu *Setujui*. Nilai: isi, lalu *Sahkan & publikasikan*. |
| | Peserta | Tab Survei: *Ambil kode* → isi Google Form → *Saya sudah mengirim formulir*. Admin menekan *Ditemukan & lengkap*. |
| 5. Selesai | Sekretariat / Admin | Setelah hari terakhir: tab Presensi → *Buat rekap*. |
| | Ketua KSM | *Sahkan & kunci*. |
| | Admin Kordik, lalu Tim Kordik | Tab Survei & penyelesaian: semua baris *Lengkap* → *Ajukan penyelesaian* → *Setujui penyelesaian*. |

## Akun

- *Akun saya* (kanan atas): lihat data akun dan ganti kata sandi sendiri.
- Peserta baru membuat kata sandi dari tautan sekali pakai yang diberikan Admin (berlaku 60 menit). Bila kedaluwarsa, gunakan *Lupa kata sandi?* atau minta Admin mengatur ulang.

## Bila tombol tidak muncul

Baca kalimat *Langkah berikutnya* di halaman penempatan: di sana tertulis siapa yang harus bertindak. Tombol hanya muncul bagi orang yang berwenang pada tahap itu.

| Yang terlihat | Artinya |
|---|---|
| Berkas *Menunggu pemeriksaan keamanan* | Pemindai berkas belum selesai atau belum terpasang. Dokumen belum bisa dinyatakan valid. |
| Tab tidak tampil | Modul itu memang tidak terbuka untuk peran atau penugasan Anda. |
| *Hadir* tidak tampil | Belum ada jadwal terbit pada tanggal itu. |
| *Ajukan penyelesaian* tidak tampil | Masih ada baris kelengkapan berstatus *Belum*; tekan *Buka →* di baris tersebut. |

## Tempat pengaturan

Menu *Pengaturan* (petugas): pengguna, role, data master, lisensi pendidik, persyaratan dokumen, template penilaian, tautan survei, kelompok KSM, arsip, dan audit log.
